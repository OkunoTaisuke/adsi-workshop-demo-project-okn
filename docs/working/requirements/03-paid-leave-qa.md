# 有給休暇申請機能 — Q&A 記録

## 第1ラウンド

[Question 1] 有給休暇の付与ルールはどうしますか？
[Answer] (A) 労基法に準拠した自動付与（勤続年数に応じて 10〜20 日）

[Question 2] 申請できる休暇の単位はどれですか？
[Answer] (C) 全日 + 半日 + 時間単位

[Question 3] 複数日にまたがる申請（例: 3日間連続で取得）は1件の申請として扱いますか？
[Answer] (B) 1日ずつ個別に申請する

[Question 4] 承認フローは勤怠修正と同じパターン（所属部署の上長が承認、上長は自己承認）でよいですか？
[Answer] (A) 同じパターンでよい

[Question 5] 有給休暇を取得した日は、打刻なしでも欠勤扱いにしない（月次集計に影響する）という理解でよいですか？
[Answer] (A) はい、有給取得日は欠勤日数から除外する

[Question 6] 有給の年度はどう管理しますか？（繰越・失効のルール）
[Answer] (A) 4月始まり年度で管理、前年度分の繰越あり

[Question 7] 申請の取り下げ（キャンセル）は可能ですか？
[Answer] (B) 承認後でも取り下げ可能（残日数が戻る）

## 第2ラウンド

[Question 8] 時間単位年休について — 労基法では年5日分（例: 所定労働8h × 5日 = 40時間）が上限です。この上限を適用しますか？また最小単位は1時間ですか？
[Answer] (A) 年5日分上限を適用、最小単位1時間

[Question 9] 有給付与の基準日について
[Answer] (A) 入社日起算で付与日を計算し、4月年度に読み替えて管理する

[Question 10] 繰越の上限について
[Answer] (A) 2年時効を適用する（前年度分のみ繰越可能、前々年度分は消滅）

[Question 11] 半日休暇の定義
[Answer] (B) 時間帯は問わず「0.5日」として消化するだけ（打刻との連動は不要）

[Question 12] 有給取得日に打刻がある場合（半日休暇+半日出勤など）の勤務時間計算
[Answer] (A) 半日休暇の日は実打刻の勤務時間のみ計算する（残業判定の基準も4時間に変わる）
